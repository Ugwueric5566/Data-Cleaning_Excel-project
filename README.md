# Data cleaning_ Google sheet project.

End-to-end data cleaning and preparation project using Google sheet, with documented steps for improving data quality and consistency.

project Overview

This project demonstrates the process of cleaning and preparing a raw dataset for analysis using Microsoft Excel.

The objective was to identify and correct data-quality issues such as duplicate records, missing values, inconsistent formatting, and invalid entries.

Tools Used
▶ Google sheet
▶ Github

Data Cleaning Process

The following steps were performed during the data-cleaning process:

1. Data Inspection

I reviewed the dataset to understand:

Number of rows and columns
Column names
Data types
Missing values
Duplicate records
Inconsistent entries

2. Duplicate Check

I checked the dataset for duplicate records and removed duplicates where necessary.

Reason: Duplicate records can affect calculations and produce inaccurate analytical results.

5. Data Validation

I applied Excel Data Validation where appropriate to ensure that entries followed the required format or available options.

4. Filtering

I used Excel's Filter feature to inspect individual columns and identify unusual or inconsistent values.

6. Formatting

I standardized the formatting of relevant columns, including:

Dates
Text
Numerical values
Column headings, including placing the currency symbols in the right columns
